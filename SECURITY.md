# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities, exposed credentials, or
private incident material.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository.
Otherwise, contact the repository owner privately through the GitHub profile and include:

- a clear description of the issue;
- affected files, commits, or workflows;
- steps to reproduce or validate the issue; and
- any suggested mitigation.

Allow reasonable time for investigation and remediation before public disclosure. Do not
include secrets, personal data, victim data, or restricted incident material in reports.

## Scope

This policy covers the repository source, prompt, example reports, documentation, and GitHub
Actions workflows. Generated reports produced by users are outside this repository's scope.
